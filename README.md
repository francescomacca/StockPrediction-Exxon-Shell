# Stock Prediction with ML and LSTM
This project analyzes the historical stock prices of Exxon and Shell.  
It compares multiple ML models:
- Lasso Regression
- Random Forest
- Gradient Boosting
- XGBoost
- LSTM (Deep Learning)
